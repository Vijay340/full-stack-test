## 2. How would you track down a performance issue in production? Have you ever had to do this?

First, I would identify whether the issue is from frontend, backend, database, or server resources.

My approach would be:
1. Check browser developer tools for slow requests
2. Inspect network/API response times
3. Analyze server logs and error logs
4. Monitor database queries
5. Use profiling/debugging tools
6. Optimize heavy queries, images, or loops
7. Test fixes in staging before production deployment

Yes, I have worked on performance-related issues such as slow page loading caused by large images, unnecessary queries, existing code optimization.
